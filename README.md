index — 32 stories across 6 regions.

- **COP31** — new draft tabled at dawn in Antalya, still no deal
- **Iran hits US bases in Bahrain** — two sites struck, industrial fire
- **Peru quake M6.7** — 152 homes uninhabitable in the Andes
- **Sparta II ablaze** — drone hit in the Gulf of Finland, crew escapes
- **Kryvyi Rih** — missile hits Zelenskyy's home city in a 400-drone barrage
- **Sinaloa** — cartel kingpin "El Chapo Isidro" seized
- **New Delhi** — Nepal PM Balendra Shah begins a state visit

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Pure Python 3 standard library, no network. Deterministic: two runs write
identical bytes.
